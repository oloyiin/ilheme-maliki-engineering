# Portfolio - React + Vite + TypeScript

## Prerequisites

- Node.js `>=20.19.0 <23`
- npm `>=10`

Recommended with `nvm`:

```sh
nvm install
nvm use
```

## Run locally

```sh
npm install
npm run dev
```

The app runs on [http://localhost:8080](http://localhost:8080).

## Available scripts

```sh
npm run dev        # start local dev server
npm run build      # production build
npm run build:dev  # development-mode build
npm run preview    # preview build output
npm run lint       # run ESLint
npm run test       # run tests once
npm run test:watch # watch mode tests
```

## Troubleshooting

- `npm: command not found` or `node: command not found`: install Node.js (prefer `nvm`), then reopen your terminal.
- Wrong Node version: run `nvm use` in the project root.
